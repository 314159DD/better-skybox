# Better Skybox: Plugin Hub readiness plan

Written 2026-09-09 after the hub-readiness review (`.superpowers/sdd/hub-ready-review.md`, Opus, master 5d35239).
This file is the source of truth for the road to the RuneLite Plugin Hub. Task briefs are cut from here.

## Decisions (Steven, 2026-09-09)

1. Ship as a Plugin Hub plugin named **Better Skybox** ("Skybox" is taken by a flat-colour plugin).
2. Replacement renderer like 117 HD (`conflicts = GPU, 117 HD`), NOT an add-on: RuneLite has one DrawCallbacks slot and the
   stock GPU plugin has no sky hook. Stock GPU settings are imported on first start so it feels like an add-on.
3. Keep the 20 CC0 skies as full-quality PNG (35 MB jar) and explain the size on the page. Only remove what is truly
   unnecessary: RS3 rips are gone (5d35239). Star map stays RGB (Milky Way tint is real and the shader shows it).
   The hub README and the review wiki document NO jar size cap (checked 2026-09-09). Ask the hub maintainers on Discord
   before opening the PR anyway; fallback if they object: optional sky pack download into `~/.runelite/better-skybox/`.
4. The javaagent stays as the dev/sideload path, split out of the hub build.

## The page

The hub card shows icon, name, author, description, tags. Everything else (screenshots, settings, FAQ) lives in the
GitHub README that the card links to. English, no em dashes.

**Card**
- displayName: Better Skybox
- author: Steven Obst
- description (hub limit is short, one sentence): Real skies for the standard GPU renderer: cubemap and procedural skies,
  day/night cycle, moon phases, stars, weather, per-area skies and fog.
- tags: gpu, skybox, sky, graphics, immersion, day night, weather
- icon.png in the repo root (size per hub README, check when cutting hub-1)

**README sections**
1. Hero: three screenshots (Lumbridge day, night with the star map, Wilderness lightning).
2. What it is, in three sentences: the standard GPU renderer with a sky pass; NOT 117 HD, the game looks exactly like
   vanilla GPU except the sky; turn it on and GPU turns off, your GPU settings are carried over.
3. Why 35 MB: twenty CC0 skies in full quality. Downloaded once.
4. Settings tour, one line per section (Renderer, Sky, Cubemap, Procedural, Fog).
5. Area skies: 162 areas from the 117 HD tables, time-of-day sets, moods, lightning areas.
6. Custom skies: folder layout under `~/.runelite/better-skybox/<name>/`.
7. FAQ: "Does it work with 117 HD" (no, it replaces the renderer, same as 117 HD does), "Does it change the game
   colours" (no), "Performance" (one extra full-screen pass, negligible), "Why does GPU switch off" (one renderer slot).
8. Credits (from the current README).
